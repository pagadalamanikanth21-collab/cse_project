Project Statement — VIT Canteen Vending Machine
Problem Statement

Managing food and beverage purchases in a busy college canteen can be time-consuming and may lead to difficulties in maintaining inventory, calculating bills, and managing customer orders.

The objective of this project is to develop a console-based Canteen Vending Machine System using Python that automates the basic canteen purchasing process.

The system should allow customers to:

View available food and beverage products.

Select products and specify quantities.

Add and remove items from a shopping cart.

Calculate the total purchase amount.

Make payments using Cash, UPI, or Card.

Receive a detailed purchase receipt.

Automatically update product inventory after a successful purchase.

The system should also provide an Admin Mode that allows authorized administrators to:

View the current inventory.

Restock available products.

Monitor product availability.

The project demonstrates the practical application of Python programming concepts such as functions, dictionaries, loops, conditional statements, exception handling, input validation, and modular programming.

Objective

The main objective is to create a simple and efficient vending machine simulation that manages products, customer orders, payments, receipts, and inventory through a user-friendly command-line interface.

Expected Outcome

The completed system should provide a functional simulation of a college canteen vending machine where customers can purchase products efficiently while administrators can manage and restock inventory.

Scope

This project is designed as an educational prototype. Payment processing is simulated and does not connect to real banking, UPI, or card payment services. Future versions can include database storage, graphical interfaces, real payment gateways, authentication, and sales reporting.
